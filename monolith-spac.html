MONOLITH isn't visible to this browser — everything below is a generic fallback font. Chrome / Edge / Firefox: install it — cp fonts/MONOLITH-Variable.ttf ~/Library/Fonts/ (or double-click the file → Install Font) — and reload; restart the browser if it was already running. Safari: this cannot work there — since Safari 12, WebKit hides every locally installed third-party font from web content (anti-fingerprinting; even /Library/Fonts is hidden), so use any other browser. Embedding the font would be the only Safari workaround, and this page deliberately refuses to embed it.
